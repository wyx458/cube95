# CUBE95 · 3D 复古魔方

一个用**纯 C + Win32 GDI** 写的桌面 3D 魔方。界面复刻 Windows 95 / 扫雷的灰阶浮雕风格，只有魔方六个面的贴纸保留彩色。

双击 `rubiks.exe` 即可运行：绿色免安装，静态链接，只依赖 Windows 系统自带 DLL（GDI32 / KERNEL32 / USER32 / msvcrt），x64 Windows 可用。

## 特性

| 项目 | 说明 |
|---|---|
| 渲染 | 透视投影真 3D 立方体，背面剔除 + 画家算法深度排序 |
| 转层 | **跟手拖拽**：该层实时跟随鼠标，可停在任意中间角度；松手才吸附到最近的 90° |
| 动画 | 指令 / 打乱转层时该层贴纸连续旋转，中途可见整层斜向翻开、露出内部深灰 |
| 模型 | 54 张贴纸 = (位置 p, 法向 n, 颜色)，绕轴整数旋转驱动，**无硬编码置换表** |
| 架构 | 统一转层控制器 `Turn`：手势层判定轴/层/方向，控制层输出单一 `render_angle`，渲染层不关心角度来源 |
| 界面 | 扫雷式黑底七段数码管（步数 / 时间）、Win95 双层浮雕、固定竖长窄窗口（520×600，不可缩放） |
| 存档 | 状态自动保存，重开程序继续 |

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖动 | 跟手转层：层实时跟随鼠标，**停在任意中间角度都可以**；松手吸附到最近的 90°。拖不满 45° 松手会弹回原位且不计步数 |
| 右键拖动 | 自由旋转视角，不计步数；向下拖 = 俯视，向上拖 = 仰视 |
| 主视角 | 恢复默认斜视角 |
| 打乱 | 生成 22 条随机指令填入输入框，经指令通道快速动画播放 |
| 复位 | 六面同色，步数与计时清零 |
| 说明书 | 打开操作说明弹窗 |
| 指令输入框 | 输入后按 Enter 或点「输入」执行 |

快捷键：`F1` 说明 · `F2` 打乱 · `Esc` 中止播放 · `Enter` 聚焦输入框。打乱后第一步自动计时，六面同色停表。

窗口没有菜单栏，也没有状态行；底部只有一行：`主视角  打乱  复位  说明书  指令: [输入框] 输入`。必要的短反馈显示在窗口标题栏，4 秒后自动消失。

## 指令

指令通道**只负责转动魔方**，视角不进通道。

- 六个面：`U` `D` `L` `R` `F` `B`；三个中间切片：`M` `E` `S`
- `'`、`’` 或小写 = 反向；`2` = 转 180°
- 多条指令用空格分隔，也可连写：`R U R' U' F2 M` 等价于 `RUR'U'F2M`
- `reset`（大小写不敏感）= 直接复位
- 出现非法字符时整串不执行

示例：`R U R' U' F2 M`

## 转层控制器（v0.2）

参考 Web 版 three.js 魔方的手势模型，把三种角度来源统一为一条渲染管线：

| 状态 | 逻辑状态 | 渲染角度 |
|---|---|---|
| `T_NONE` | 已提交 | 0 |
| `T_DRAG` | **未提交** | 鼠标累积角 `A`，随停随住，无时间驱动 |
| `T_TWEEN` | 已提交 | 从 `t_from` 平滑回到 0（松手吸附 / 指令动画） |

松手时令 `k = round(A / 90°)`，先提交 `rotate_layer(k)`，再以 `t_from = A - k*90°` 开始补间。利用旋转可加性 `rot(k, A − k·90°) = rot(0, A)`，松手瞬间视觉零跳变。拖拽期间命令队列暂停，逻辑状态不会被中途改写。

## 编译

需要 MinGW-w64 GCC（推荐 [w64devkit](https://github.com/skeeto/w64devkit)）。把 `bin\gcc.exe` 加入 PATH，或解压到项目下的 `.toolchain\w64devkit\`，然后双击 `build.bat` 即可。

```bat
gcc -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -static -mwindows ^
    rubiks.c -o rubiks.exe -lm -lgdi32 -luser32
```

`build.bat` 还会构建带 `SELFTEST` 宏的自检程序并运行 **45 项**逻辑自检，覆盖坐标旋转、浮点动画与整数转层在 90° 处严格一致、指令解析与非法字符拒绝、视角拖拽方向与钳制，以及 v0.2 的吸附映射、松手零跳变、补间幅度 ≤45°、拖拽限幅与窗口比例。
